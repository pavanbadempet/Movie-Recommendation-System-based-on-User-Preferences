# API Reference

Complete reference for the APEX Recommendation API v2.0.

Interactive docs (Swagger UI) are available at `/docs` on any running instance.

**Static docs (no server required):**
- [`docs/swagger-ui.html`](swagger-ui.html) — Swagger UI loaded from `openapi.json`
- [`docs/openapi.json`](openapi.json) — Machine-readable OpenAPI 3.1 spec (52 endpoints, 19 schemas)
- [`docs/openapi.yaml`](openapi.yaml) — Human-readable YAML version

The spec is auto-generated by `scripts/export_openapi_spec.py` and validated in CI on every push.

## Authentication

Most endpoints are public. Admin endpoints require a Bearer token.

```http
Authorization: Bearer <NOVA_ADMIN_TOKEN>
```

Multi-tenant B2B endpoints accept an API key header:
```http
X-Nova-API-Key: <api_key>
```

JWT tokens for user-scoped endpoints:
```http
Authorization: Bearer <jwt_token>
```

## Core Endpoints

### Health & Status

#### `GET /health`

Lightweight health check. Does not load the recommender (fast cold-start probe).

**Response:**
```json
{
  "status": "ok",
  "movie_count": 10247,
  "app_version": "2.0.0",
  "app_commit": "abc1234",
  "serving_tier": "tier3",
  "hardware_profile": {
    "gpu_available": false,
    "ram_gb": 0.5,
    "cpu_cores": 1
  },
  "tier_selection_reason": "legacy_profile_mapping"
}
```

#### `GET /v1/platform/readiness`

Detailed readiness probe. Runs smoke tests on search, recommendations, and benchmarks.

**Query parameters:**
| Parameter | Type | Default | Description |
|---|---|---|---|
| `strict` | bool | `false` | If `true`, benchmark cache misses count as degraded |
| `k` | int | `10` | Top-k for smoke test recommendations |

**Response:** Component-level status for `catalog`, `artifact_health`, `vector_serving`, `search_smoke`, `recommendation_smoke`, `semantic_benchmark_cache`, `recommendation_benchmark_cache`, `learned_ranker`, `event_store`.

#### `GET /v1/platform/slo`

SLO report with per-route p50/p95 latency and error rate.

### Recommendations

#### `GET /v1/recommendations/id/{movie_id}`

Core recommendation endpoint. Returns movies similar to the given movie using the full ensemble pipeline (retrieval → ranking → reranking).

**Path parameters:**
| Parameter | Type | Description |
|---|---|---|
| `movie_id` | int | TMDB movie ID |

**Query parameters:**
| Parameter | Type | Default | Description |
|---|---|---|---|
| `n` | int | `10` | Number of recommendations (1–50) |
| `explain` | bool | `false` | Append LLM-generated natural-language explanation (requires `OPENROUTER_API_KEY`) |
| `user_id` | string | — | User ID for personalization and event logging |
| `session_id` | string | — | Session ID for event logging |
| `request_id` | string | — | Idempotency key |

**Response:**
```json
{
  "request_id": "uuid",
  "query_movie": {
    "id": 155,
    "title": "The Dark Knight",
    "genres": "Action, Crime, Drama",
    "vote_average": 9.0
  },
  "recommendations": [
    {
      "id": 49026,
      "title": "The Dark Knight Rises",
      "similarity_score": 0.967,
      "ranker_score": 0.891,
      "retrieval_stage": "content_sparse_fallback",
      "retrieval_signals": { "faiss_rank": 1, "tfidf_rank": 1 },
      "explanation": ["Shared genres: Action, Crime", "Same director (Christopher Nolan)"],
      "explanation_text": "Because you loved The Dark Knight, you'll enjoy The Dark Knight Rises..."
    }
  ]
}
```

#### `GET /v1/recommendations/visually-similar/{movie_id}`

Multi-modal recommendation using CLIP (visual) + SBERT (semantic) fusion. Finds movies with similar aesthetic and thematic qualities based on poster imagery and plot text.

Same parameters as `/v1/recommendations/id/{movie_id}`.

#### `GET /v1/recommendations/knowledge-graph/{movie_id}`

Multi-hop semantic reasoning via NetworkX knowledge graph. Traverses `Movie → Theme → Movie` and `Movie → Director → Movie` edges.

Same parameters as `/v1/recommendations/id/{movie_id}`.

#### `GET /v1/recommendations/user/{user_id}`

Personalized recommendations based on the user's interaction history.

**Query parameters:**
| Parameter | Type | Default | Description |
|---|---|---|---|
| `n` | int | `10` | Number of recommendations |
| `explain` | bool | `false` | LLM explanations |

### Search

#### `GET /v1/search/ai`

Dense vector semantic search. Handles misspellings, abstract concepts, and mood-based queries.

**Query parameters:**
| Parameter | Type | Required | Description |
|---|---|---|---|
| `q` | string | Yes | Search query (e.g., "mind-bending thriller", "movies like Inception") |
| `limit` | int | No (default: 20) | Number of results (1–100) |
| `top_k` | int | No | Override for limit parameter |

**Response:** List of movies matching the query.

#### `GET /v1/search`

Hybrid search (dense + sparse). Combines FAISS semantic search with TF-IDF keyword matching.

**Query parameters:**
| Parameter | Type | Required | Description |
|---|---|---|---|
| `q` | string | Yes | Search query |
| `limit` | int | No (default: 20) | Number of results (1–100) |

#### `GET /v1/movies/titles`

Autocomplete endpoint. Returns lightweight `{id, title}` pairs for search suggestions.

**Query parameters:**
| Parameter | Type | Description |
|---|---|---|
| `q` | string | Prefix query |
| `limit` | int | Max results (default: 20) |

### Events

#### `POST /v1/events`

Ingest a user behavior event. Used for online learning, A/B testing, and analytics.

**Request body:**
```json
{
  "event_type": "click",
  "movie_id": 155,
  "user_id": "user_123",
  "session_id": "session_abc",
  "request_id": "uuid",
  "rating": null,
  "metadata": {}
}
```

**Supported `event_type` values:** `view`, `search`, `click`, `rating`, `recommendation_request`, `recommendation_impression`

**Side effects:**
- `click` and `rating` events trigger `OnlineLearner.enqueue` for real-time LightGCN updates
- `rating` ≥ 4.0 or ≤ 2.0 triggers `ActiveInferenceEngine.self_heal` as a background task

### Evaluation

#### `GET /v1/evaluation/semantic-benchmark`

Runs the 17-case semantic benchmark and returns HR@10, NDCG@10, MRR, and bad-hit rate.

**Query parameters:**
| Parameter | Type | Default | Description |
|---|---|---|---|
| `k` | int | `10` | Top-k cutoff |
| `use_cache` | bool | `true` | Return cached result if available |

#### `GET /v1/evaluation/recommendation-benchmark`

Runs the recommendation quality benchmark against curated test cases.

#### `GET /v1/evaluation/offline`

Returns the offline evaluation report from `reports/offline_eval_report.json`.

### Admin

All admin endpoints require `Authorization: Bearer <NOVA_ADMIN_TOKEN>`.

#### `POST /v1/admin/reload-ensemble-weights`

Hot-reloads `models/ensemble_weights.json` without restarting the server.

**Response:**
```json
{
  "status": "ok",
  "weights": {
    "lightgcn": 0.005,
    "sasrec": 0.659,
    "kan": 0.298,
    ...
  }
}
```

#### `POST /v1/admin/reload-recommender`

Reloads all serving artifacts (FAISS index, embeddings, model weights) without restarting.

**Query parameters:**
| Parameter | Type | Default | Description |
|---|---|---|---|
| `force_download` | bool | `false` | Force re-download from Hugging Face Hub |

#### `GET /v1/admin/platform-status`

Full platform status including artifact health, experiment state, and remote recommender status.

## Error Responses

All errors follow a consistent format:

```json
{
  "detail": "Movie with id 99999 not found in catalog"
}
```

| Status Code | Meaning |
|---|---|
| `400` | Bad request — invalid parameters |
| `401` | Unauthorized — missing or invalid token |
| `404` | Not found — movie ID not in catalog |
| `422` | Validation error — request body schema mismatch |
| `429` | Rate limited — 30 requests/minute per IP |
| `500` | Internal server error — check `/health` for component status |

---

## Rate Limiting

Public endpoints: **30 requests/minute per IP** (enforced by slowapi).

B2B tenants with API keys have plan-based quotas enforced by the Redis token bucket middleware. Contact the admin to configure custom quotas.

---

## Pagination

Endpoints that return lists accept `limit` (default: 10, max: 50). Cursor-based pagination is not currently implemented — use `limit` to control result size.

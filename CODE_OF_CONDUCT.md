# Code of Conduct

## Expected behavior

Contributors must communicate respectfully, review technical claims on evidence, accept constructive feedback, and avoid harassment, discrimination, threats, or disclosure of private information.

## Scope

This applies to repository discussions, issues, pull requests, reviews, community channels, and public representation of the project.

## Reporting and enforcement

Report conduct concerns privately to the repository maintainers through the contact method listed on the GitHub repository. Maintainers may edit or remove content, issue warnings, temporarily restrict participation, or permanently ban participants when necessary.

Reports will be handled as confidentially as practical. Retaliation against a reporter is prohibited.
